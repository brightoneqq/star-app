Try/catch around the bridge returns `500 dev bridge error: <msg>` so a thrown error from `app.fetch` doesn't crash the Node server. |

## Requirements Traced

- **Dev convenience supporting R8 verification** — provides a local `npm run dev` path so `/api/*` routes can be tested with `curl http://localhost:8000/api/health` without invoking the EdgeOne CLI.
- **No new dependencies** — env-loader is hand-rolled (~15 lines) to honor the spec's "exactly two deps" budget; dotenv is not added.
- **Edge-runtime parity** — bridge passes a WHATWG `Request` + `env` object to `app.fetch`, matching the signature used by `functions/api/[[path]].js` (task 9). The `duplex: 'half'` flag is required by Node 18+ when constructing a `Request` with a body, otherwise `fetch`/`Request` throws.
