## Requirements Traced

- **R7#2 (idempotent + PRAGMA check)** — All `CREATE` statements rely on `IF NOT EXISTS` (delegated to libSQL). `ALTER TABLE ADD COLUMN` is guarded by a PRAGMA `table_info` lookup, since libSQL has no `IF NOT EXISTS` for ADD COLUMN.
- **R7#3 (non-destructive)** — Runner only executes statements as-given; no `DROP` / `TRUNCATE` emitted by the runner itself. Existing `001`/`002` migrations are CREATE-only.
- **R7#5 (additive schema evolution)** — Future migrations can use `ALTER TABLE ADD COLUMN` and the runner will be idempotent across reruns via the PRAGMA gate.
- **Fail-fast** — env validation at startup (per design.md "Fail-fast behavior"): missing/empty env → `[migrate] missing env` + exit 1, before any client creation.
