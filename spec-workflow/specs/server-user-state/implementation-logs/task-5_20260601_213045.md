## Requirements Traced

- **R1#2 (code regex 6–16)** — `validateCode` enforces `/^[a-zA-Z0-9_\-]{6,16}$/` plus a `typeof === 'string'` guard so non-string inputs (null/undefined/number) return false without throwing.
- **R2#6 (64KB cap)** — `payloadByteLength` measures UTF-8 byte length via `TextEncoder` so callers (task 8 PUT) can compare against 65536 and return 413 when exceeded. Uses real byte count, not `.length` (which counts UTF-16 code units).
- **R7#1 (Turso connection)** — `getDb` returns a libSQL client wired to `env.TURSO_DATABASE_URL` + `env.TURSO_AUTH_TOKEN`. Per-request shape leaves no long-lived global state on the edge instance (steering anti-pattern compliance).
- **Edge-runtime safety** — `@libsql/client/web` is the fetch-transport flavor with no `node:*` imports, which is the only flavor that works inside EdgeOne Pages Functions. The default `@libsql/client` import is reserved for the Node migration runner.
