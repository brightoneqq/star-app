## Requirements Traced

- **R3#3 (PUT 204/400/413)** — PUT returns 204 on success, 400 on malformed/invalid body, 413 when `payloadByteLength(rawBody) > 65536`. `bytes` is set on context BEFORE the 413 branch so the log line reflects the rejected payload size.

- **R9#3 (DELETE idempotent)** — DELETE returns 204 unconditionally after `db.execute` resolves (never inspects `rowsAffected`); double-deletes and unknown codes both succeed silently.
- **R10#1 (413)** — PUT short-circuits with 413 + JSON error when payload exceeds 64KB.
- **R10#2 (429 + Retry-After)** — PUT calls `checkAndIncrement(db, ip)` after body validation; on `!allowed` sets `Retry-After` header to `String(rl.resetInSeconds)` and returns 429 with JSON error body.
