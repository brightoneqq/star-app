# 首页改版（homepage-redesign）— 需求文档

## 概述

把现在「大标题 + 副标题 + 一个重点集按钮 + 两张白卡」的首页（`index.html`），改成**多邻国式的活泼学习 App 首页**：增加顶部引导区（streak / 今日 / 总进度 + 推荐下一课），让单元卡片更大更有冲击力并带状态徽章，整体换成多邻国绿主色调。目的是让小朋友打开 iPad 就想点。

## 用户故事

- 作为用 iPad 的小朋友，**我想一眼看到自己今天/这段时间学了多少**，从而有继续下去的动力。
- 作为用 iPad 的小朋友，**我想被告诉「下一个该练哪一课」**，不用自己判断从哪开始。
- 作为用 iPad 的小朋友，**我想点开首页就觉得这是个有趣的学习 App**，而不是个表格。

## 功能需求

### 顶部区域（标题栏）

- [ ] 保留 `课间复习` 主标题和 `选一个 Unit 开始复习或自测` 副标题。
- [ ] 保留右上角胶囊按钮 `⭐ 重点集`，但加数字徽章：`⭐ 重点集 (N)`，N = 所有 `starredCards_<slug>` 长度之和。
  - 当 N=0 时不显示括号数字（避免 `(0)` 难看）。

### 引导区（标题下方，顺序固定）

#### 第一行：三个小卡横排

布局上自适应——窄屏时三个均分一行，间距不可过窄（≥ 8px），文字不可换行（用 `white-space: nowrap` 或缩短文案）。

1. **🔥 连续学习 N 天**
   - 数据：基于一个新的 localStorage key `mystar_active_days`（字符串数组，元素是 `YYYY-MM-DD`），每次进入首页或任意 Unit 时把今天的日期加进去（去重）。
   - 连续数 = 从今天倒推、未中断的连续天数；中断后归 0。
   - N=0 时显示"开始学习吧"占位文案，不显示 🔥。
   - N ≥ 1 时显示 🔥 + N 天。

2. **今日 N 个**
   - 当天 `lastVisit_<slug>` 日期等于今天的 unit 数量。
   - N=0 时显示"今日 0 个"，不隐藏。

3. **掌握 N/M 词**
   - M = `MYSTAR_MANIFEST.books` 下所有 unit 的 `cardCount` 之和。
   - N = 已"掌握"的 unit 的 cardCount 之和。"掌握" = 该 unit 的 `quizScore_<slug>` ≥ 90。
   - 显示成「掌握 132/240 词」。

#### 第二行：推荐下一课大卡

- 标题：`推荐下一课`
- 主体：显示一个 Unit 的 `number`（U6）、`title`（Unit 6 · Famous people in history）、辅助信息（最近复习时间 + 重点数）。
- 右侧一个 `▶ 开始` CTA 按钮，整卡可点，点击效果与下方单元卡相同（跳到 `units/<book>/<slug>/index.html`）。
- **推荐算法**：所有 unit 按 `starredCards_<slug>` 长度倒序，取第一个。
  - **平手时**：先按 `quizScore_<slug>` 升序（低分优先），再按 `lastVisit_<slug>` 升序（久未复习优先）。
  - **所有 unit 都没有重点卡时**：fallback 到"最久未复习"（lastVisit 为空的优先，否则取最早）。
- 当只有 1 个 unit 时仍展示推荐卡（即"接着练这个"）。

### 书籍 / 单元列表

- [ ] 保留 `BOOK 1 · 课本一` 这种小标题样式。
- [ ] 单元卡片改成"更大更有冲击力"的版本：
  - 左侧：圆角徽章（`U3`、`U6`），多邻国绿主色或按状态着色。
  - 主体：标题（`Unit 6 · Famous people in history`）+ 一行 meta（`32 词 · 180 空`）。
  - 第二行 meta（新增）：`⏱ 2 天前 · ✓ 92% · ⭐ 5`（这三个值有就显示，没有就跳过整段）。
  - 右上或右侧：**状态徽章**（颜色 + 短文案）：
    - `未开始` — 灰色 — `lastVisit` 为空
    - `进行中` — 蓝色（沿用现有 #2563EB） — 有 `lastVisit` 但 `quizScore < 90`
    - `掌握` — 多邻国绿 — `quizScore ≥ 90`
  - 整卡可点，点击跳到原 `units/<book>/<slug>/index.html`。

### 配色 & 视觉

- [ ] 主色调改为**多邻国绿** `#58CC02`（CTA、推荐卡、掌握状态、首页强调色）。
- [ ] **进行中**状态保留蓝色（沿用 `#2563EB`）作为辅助色。
- [ ] streak / 数字强调可用暖色 `#FF9600`（多邻国橙），但只用一处，避免乱。
- [ ] 文字层级：标题黑、副标题中灰、meta 浅灰，沿用现有 CSS 变量风格。

### 装饰

- [ ] 允许内联 SVG 图标（🔥火焰、⭐星星、✓勾、▶播放、⏱时钟）。每个图标必须以 ES5 兼容的字符串形式直接写在 HTML 或 CSS background 里。
- [ ] 也允许 emoji 兜底（🔥 ⭐ ✓ ▶ ⏱），如果 SVG 调起来麻烦就 fallback 到 emoji。
- [ ] **不引入任何外部图标库或字体**。

### 动效

- [ ] **入场动画（首屏一次）**：标题、引导区、推荐卡、单元列表 4 段，按顺序 fade-in + 轻微 translateY，每段间隔 80ms，总时长 ≤ 400ms。
- [ ] **tap 反馈**：所有可点元素（重点集按钮、推荐大卡、单元卡）`:active` 时 `transform: scale(0.97)`，过渡 ≤ 120ms。
- [ ] **数字进度条 / streak 更新**：先静态显示不做数字滚动动画（老 iPad 性能不值得）。
- [ ] 所有动画必须用 CSS `transition` / `animation`，**不用 requestAnimationFrame**，不用 JS 动画库。
- [ ] 用 `prefers-reduced-motion` 媒体查询禁用入场动画。

### 桌面 / 响应式

- [ ] 整页用 `max-width: 640px` 居中。
- [ ] 不做多列布局。iPad 竖屏是主场景。
- [ ] 引导区三小卡横排在窄屏（≤ 360px）下可缩字号 / 缩 padding，但不换两行。

## 非功能需求

- **性能**：首屏不引入额外 JS。所有计算（streak / 总进度 / 推荐）在 `index.html` 现有的 `render()` 里完成，单次循环搞定。
- **存储**：新增一个 key `mystar_active_days`，存 `YYYY-MM-DD` 字符串数组。**必须通过 `MyStar.readJSON/writeJSON`** 写入，享受 cookie 兜底。Cookie 大小预算注意：每天 11 字节，5 年也才 ~20KB——可接受，但建议**最多保留最近 400 天**，超出从头部裁掉。
- **兼容性**：老 iPad Safari 必须能跑。ES5 only（`var`、`function`、IIFE）。SVG 用最小子集（`path` / `circle`，不用 `<use>`、不用 mask）。
- **不引入依赖**：禁止 npm/CDN/字体/图标库。
- **中文 UI 保留**：所有中文文案不得改成英文。

## 边界情况与错误处理

| 场景                                  | 期望行为                                                          |
|---------------------------------------|-------------------------------------------------------------------|
| 没有任何 unit 被打开过                | streak=0、今日=0、掌握=0/M、推荐卡默认推第一本书第一个 unit       |
| 所有 unit 都没有重点卡                | 推荐卡用"最久未复习"的 unit                                       |
| 只有 1 个 unit                        | 推荐卡 = 那个 unit；它本身列表里也展示，重复展示可接受             |
| 用户跨天进入但没做任何 quiz           | streak 仍 +1（"打开 App"算有效活动）                              |
| 用户清掉 localStorage                 | 所有计数归零，正常运行，不报错                                    |
| `MYSTAR_MANIFEST` 为空                | 顶部引导区数字全 0，列表区显示"暂无内容"                          |
| cookie/localStorage 双失败            | 已有的 `MyStar.readJSON` 返回 null，不抛异常；UI 当作"没数据"      |
| 同一天打开多次                        | `mystar_active_days` 去重，不影响 streak                          |
| 入场动画在 prefers-reduced-motion 下  | 一律跳过，直接渲染最终态                                          |

## 数据模型

新增一个 localStorage key：

```
mystar_active_days  : string[]   // 形如 ["2026-05-25", "2026-05-26", "2026-05-27"]
                                 // 升序去重，最多 400 项
```

复用现有 key（不动数据结构）：

```
starredCards_<slug> : string[]        // 已有，重点卡 ID 列表
lastVisit_<slug>    : number          // 已有，时间戳
quizScore_<slug>    : number          // 已有，0-100
```

## 假设清单（请确认）

1. streak 的"有效活动"定义 = **打开过首页或任何 Unit 页面**。不需要做题、不需要点 quiz。
2. streak 跨天清零策略 = **错过一天直接归 0**（多邻国玩法）。
3. 单元卡上"最近时间 / quiz 分 / 重点数"三段 meta，有就显示，没有就整段跳过——不显示"--"占位。
4. 入场动画 4 段顺序：标题 → 三小卡 → 推荐大卡 → 单元列表。
5. SVG 图标若实现成本高，允许 fallback 到 emoji，**这一选择由实现阶段决定**（不阻塞需求）。
6. 即使 `manifest` 只有一个 unit，推荐大卡仍展示（不去重列表）。
7. 推荐大卡和单元列表里的卡都用同一种 tap 反馈和点击逻辑。
8. 配色：主色 `#58CC02`，进行中 `#2563EB`，强调 `#FF9600`，文字沿用现有色阶。具体 hover/active 色阶在实现时确定。
9. 桌面端 `max-width: 640px`，全局居中，不做多列。
10. `prefers-reduced-motion: reduce` 下禁用所有入场动画。

## 未决问题

## 不在范围内

- 不改单元页（`units/<book>/<slug>/index.html`）内部布局。
- 不改重点集页（`review/index.html`）内部布局；只调整入口按钮样式 + 数字徽章。
- 不做账号 / 云同步 / 跨设备状态。
- 不做主题切换（暗色模式、字体大小调整）。
- 不做"勋章 / 关卡 / 经验值"系统——只有 streak / 今日 / 掌握三个最基础指标。
- 不引入 PWA / 离线缓存。
- 不做国际化（保留中文）。
