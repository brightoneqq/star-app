  - `tierForScore(score)` — returns `'tier-high'` for `score >= 80`, `'tier-mid'` for `60 <= score < 80`, `'tier-low'` otherwise. Coerces input via `Number(score)` for defensive numeric comparison.
  - `updateCardBadge(cardEl, score)` — finds `.card-actions` inside `cardEl`; no-op if missing. Finds existing `.card-score-badge` span or creates a new one and inserts it as the first child of `.card-actions` (before `.btn-star` / `.btn-card-toggle`). Sets `className = 'card-score-badge ' + tierForScore(score)` and `textContent = '上次 ' + score + '%'`. Idempotent: re-calling with a new score updates class and text in place.
  - `renderInitialCardBadges()` — iterates `document.querySelectorAll('.vocab-card[id]')` via `Array.prototype.forEach.call`. For each card reads `MyStar.readNumber('quizScore_' + SLUG + '_' + cardEl.id)`. If non-null and not `NaN`, calls `updateCardBadge`. Cards without a stored score get no badge — no placeholder rendered.
  - `refreshAllCardBadges(byCard)` — no-op when `byCard` is falsy. Walks own keys of `byCard` via `for...in` + `hasOwnProperty` guard; for each `cid`, looks up `document.getElementById(cid)` and calls `updateCardBadge(cardEl, byCard[cid].score)`. Does not re-grade.
